CLAIMS STRATEGY ENGINE
================================================================================

Server-side proprietary scoring system. NOT exposed to frontend.

RULE PACKS:
  Standard (6 rules)  - General medical/surgical claims
  Emergency (4 rules) - Emergency and urgent care
  Surgical (4 rules)  - Surgical procedures

RULES:
  R001 - CPT-DX Compatibility (validates medical coding pairs)
  R002 - Medical Necessity (scores diagnosis severity)
  R003 - Timely Filing (checks filing deadlines)
  R004 - Duplicate Detection (finds duplicate claims)
  R005 - Modifier Compliance (validates CMS modifier rules)
  R006 - Bundling/Unbundling (detects NCCI edits)
  
  E001 - Emergency Qualifier
  E002 - Level of Care
  E003 - Out-of-Network Override
  E004 - Documentation Completeness
  
  S001 - Prior Auth Verification
  S002 - Global Period Check
  S003 - Assistant Surgeon Rules
  S004 - Bilateral Modifier

DECISION OUTPUT:
  APPROVE_SUBMIT       - Low denial risk, submit immediately
  REVIEW_RECOMMENDED   - Moderate risk, address flags
  HOLD_FOR_CORRECTION  - High risk, must correct first

CONFIDENCE METRICS:
  Rule integrity checking
  Override tracking
  Recommendation generation
